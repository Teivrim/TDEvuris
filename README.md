# TDEvuris

Набор Windows-сканеров на C++17: 13 отдельных бинарников вместо одного
монолита. **3 253 строки, ноль зависимостей** — только системные
Win32, `bcrypt`, `wintrust`, `iphlpapi`.

## 13 модулей, каждый изолирован

Один файл с подсистемой плагинов выглядит аккуратнее, но отлаживается
хуже: упавший детектор роняет всё, и непонятно какой. Здесь каждый
сканер — отдельный модуль со своим заголовком, без общего состояния:

```
src/
  boot_scanner      memory_scanner    network_scanner
  registry_scanner  shredder          hasher
  heuristics        signatures        updater
  watcher           scanner           json
```

Собирается это в один оконный бинарник: точка входа `WinMain`, печати
в консоль нет вообще (0 `printf`, 0 `std::cout`) — весь вывод через
`MessageBox`, интерфейс на Win32. В CMake это объявлено явно:

```cmake
set_target_properties(TDEvuris PROPERTIES WIN32_EXECUTABLE TRUE)
```

Без этой строки линкер ждёт `main` и падает с `LNK2019`.

Два независимых механизма детекции — подписи и эвристики. Это осознанно:
подписи дают точность и ломаются при обновлении, эвристики дают покрытие
и дают ложные срабатывания. Вместе они лучше, чем по отдельности.

`shredder` и `hasher` — не демонстрация: перезапись файла и подсчёт
хешей работают, и на них стоит остальная логика.

## Как устроено

```
src/
  main.cpp        1 691 стр. — разбор аргументов и маршрутизация
  scanner.cpp      245 стр. — обход и обследование
  signatures.cpp    50 стр. — загрузка и применение подписей
  ...
CMakeLists.txt    модули перечислены явно, каждый линкуется отдельно
```

Список модулей в `CMakeLists.txt` прописан вручную, а не через glob:
при glob-е лишний файл в каталоге молча добавляется в сборку, и через
месяц никто не помнит, откуда он взялся.

## Сборка

```bash
cmake -B build
cmake --build build
```

Требуется MSVC (используются `wintrust`, `iphlpapi`, `bcrypt`).
Результат последней сборки — в `BUILD-REPORT.md`.

## Границы — прочитайте до использования

Это **учебный проект, а не антивирус**. Конкретно:

- База подписей демонстрационная и не обновляется сама. Модуль
  `updater` умеет качать обновления, но ему нужен настоящий сервер
  с подписью — сейчас его нет.
- Антивирусное ПО и операционная система будут ругаться на бинарники.
  Это ожидаемо для самописного сканера, и это не дефект сборки.
- Обработка подозрительных файлов — в изолированной среде. Не запускайте
  на рабочей машине то, что не готовы потерять.
