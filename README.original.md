## Сборка

```
cmake -B build && cmake --build build (MSVC)
```

- **Проверка:** ✅ Сборка проверена на этой машине.
- **Время:** ~15 с

## Что внутри

- 13 отдельных бинарников-сканеров, а не один монолит
- Эвристики + подписи: два независимых механизма детекции
- Шредер файлов и хешер — реальные утилиты, а не демо
- Модульный updater с подписью обновлений
- Чистый Win32 без сторонних библиотек

## Кому подойдёт

Студентам ИБ и тем, кто хочет понять, как устроены антивирусные движки

## Чем отличается от аналогов

Нет готовых исходников такого набора на C++/Win32 с открытым кодом и без зависимостей.

## Требования

- Компилятор: MinGW-w64 g++ 14+ либо MSVC
- Сеть не нужна
